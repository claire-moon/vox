DIGS v0.0.4 DEMO - Windows x86-64
==================================

1. Extract the complete ZIP file.
2. Open the extracted folder.
3. Double-click run-digs.bat.

Keep bin/ and share/ inside the extracted folder. No separate SDL installation
is required for this package.

For an uncommon controller, copy extras\gamecontrollerdb.txt to
share\digs\controllers\gamecontrollerdb.txt before launching. The bundled
database is optional; SDL2 already recognizes common controllers.

This package is for 64-bit Windows.
