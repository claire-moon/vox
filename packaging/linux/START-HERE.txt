DIGS v0.0.3 DEMO - Linux x86_64
================================

1. Extract the complete archive.
2. Double-click run-digs.sh, or run it from a terminal:

       ./run-digs.sh

The game is a CPU-rendered SDL2 demo. SDL2 remains a system library and is not
bundled. If it is missing, the launch scripts print distribution-specific
installation commands.

Useful tester commands
----------------------

  Open QUICK-FEEDBACK.txt          guided 20-minute keyboard/mouse test lane
  ./smoke-test.sh                 non-windowed acceptance including 600-tick load
  VOX_NAMED_BENCH_QUALIFY=1 ./smoke-test.sh
                                  add strict timing only on the named laptop bench
  ./benchmark.sh 240              CPU Lightfield benchmark (three quality tiers)
  ./qa-cockpit.sh                 combine the included workbook and test evidence
  ./bin/digs_script --validate share/digs/scripts/manifest.txt
                                  validate the packaged Lua catalog
  ./bin/digs_script --hash share/digs/scripts/manifest.txt
                                  print packaged source and catalog hashes
  ./bin/vox_headless              minimal voxel-kernel scenario
  ./bin/digs_headless             deterministic DIGS match scenario
  ./bin/vox_render_demo out.ppm   software-renderer image test
  ./bin/digs_demo --input-self-test
                                  controller normalization/range self-test

Smoke images, benchmark reports, and cockpit packets go to qa/out/. Open
QUICK-FEEDBACK.txt first, then qa/README.md for the complete feedback workflow.
The cockpit requires the free xleak command-line spreadsheet reader to inspect
.xlsx feedback workbooks.

Keep bin/, bin/share, share/, and libexec/ in their extracted layout. The
bin/share link makes executable-relative data resolve under share/digs/. This
includes the Lua catalog, the pinned controller mapping database, and the
canonical miner icon. CG-README.TXT documents AUTO/keyboard/controller modes,
Logitech F310 X/D-mode checks, radial aim, two-player ownership, rope use, map
identity, the Miner's Index, accessibility options, script reload, and the
88-point acceptance pass. The short guide is defect-discovery evidence;
it does not replace the complete pass or promote untested hardware/platforms.

The evidence/ directory contains the unmodified package-time test streams,
exit statuses, smoke images, build profile, and an explanation of their
provenance. SBOM.spdx.json inventories this exact bundle and records SDL2 as
an external system library rather than bundled code. SDL GameControllerDB is
bundled data; its pinned identity and zlib notice are recorded in
THIRD_PARTY.md and LICENSES/SDL_GameControllerDB.txt.
