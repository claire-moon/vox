VOX + DIGS SUPPORT ROADMAP

Support states:
  PLANNED    design target only
  BUILDS     reproducible build exists
  RUNS       boots and completes smoke scenario
  VERIFIED   native or reproducible acceptance evidence recorded
  UNSUPPORTED explicitly not targeted by the current profile

v0.0.1 VERIFIED target:
  Linux x86-64 / current test laptop / software renderer
  (modern GPU backend and GPU/device preflight remain pending)

v0.0.2 DEVELOPMENT CANDIDATE:
  Preserve the v0.0.1 scalar CPU and evidence baseline while adding:
  - one or two local humans, zero through two bots, team/friendly-fire rules;
  - responsive fixed-point movement, steam traversal, and breakable rope;
  - controller hotplug/claim, persistent rebinding, and shared dynamic camera;
  - spawn protection, stateful bots, anatomy, varied simulated FX, and chip SFX;
  - bounded Lua 5.1 catalog, How To Play, Miner's Index, and QA coverage.

  This row is not VERIFIED by implementation or compile status alone. Promotion
  requires a frozen commit, strict automated gate, packaged-runtime script
  validation, repeatable hashes per simulation profile, controller/manual
  acceptance, reviewed QA workbook, source archive, SBOM, and checksums.

v0.0.3 STABILITY AND SYSTEMS CANDIDATE:
  Preserve the complete v0.0.2 match while correcting and extending:
  - bounded collision recovery instead of living-player spawn teleports;
  - swept anatomy hits, natural loose debris, and bounded awake reactions;
  - casting/attached rope physics, Hold/Toggle policy, and nonlethal hook hits;
  - lift-and-glide steampack feedback and a charged piercing Mining Rail;
  - device-clock audio, expanded contextual speech, controller-family prompts,
    Switch Pro haptics, 15 FPS, Laptop Mode, and close-zoom native detail;
  - camera-visible work and hard frame-cap qualification without changing the
    fixed 60 Hz match or deterministic FX profile.

  ABI 9 and settings schema 3 are intentional compatibility boundaries. This
  row remains a candidate until the v0.0.3 checklist, Linux bundle, manual
  controller/audio pass, performance soak, QA workbook, and source evidence
  are complete.

Modern future targets:
  Windows 10/11 x86-64
  macOS 11+ Intel/Apple Silicon
  Linux ARM64 and additional x86-64 distributions

Compatibility future targets:
  Windows XP/7, older i686 Linux, older Intel macOS
  OpenGL/D3D9 and software framebuffer profiles

Retro future targets:
  DOS, Windows 3.1/95/98/NT4/2000, and period Linux
  320x200/640x480 software profiles

Classic Mac future targets:
  System 7/8/9 on 68k/PPC using QuickDraw/native adapters

No platform becomes VERIFIED from a compile alone. Record the exact OS,
CPU, GPU/API, compiler, build, boot, input, render, match-completion, and
performance evidence before advertising support.

Engine milestones after the v0.0.3 acceptance gate:
  - replay/input-log format and deterministic network research;
  - broader rigid-body/joint/constraint physics behind the stable C ABI;
  - renderer-neutral snapshots plus measured OpenGL/D3D/Metal adapters;
  - streamed/larger-world profiles with explicit memory and CPU budgets;
  - QEMU automation, 86Box device-fidelity profiles, then native acceptance;
  - versioned reduced profiles for legacy and retro hosts without weakening
    the strict C89 behavioral oracle or overstating equivalence.
