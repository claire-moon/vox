# Surfaces allowed to name a version other than the one in VERSION.
# Read by tools/vox-version-check.sh.
#
# Two forms:
#
#   path                  every line in the file is exempt
#   path :: substring     only lines containing the substring are exempt
#
# Every rule needs a reason.  A rule that matches nothing fails the check --
# a stale exemption is a hole waiting for the next mistake to fall into, so
# the list cannot quietly rot.
#
# The bar for adding one: the text is describing project history, not this
# build.  "What changed since v0.0.3" has to be able to say v0.0.3.  If the
# text tells a player what to download or what they are running, it is not an
# exception; it is a bug.
