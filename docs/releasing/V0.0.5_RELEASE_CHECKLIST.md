# v0.0.5 release checklist

This checklist is intentionally prospective. The repository still identifies
the current product as v0.0.4; checking in this document does not authorize a
version bump, tag, package publication, or release.

## Before versioning

- [ ] The current sandbox baseline is merged to protected `main` through
  review, with its deterministic load hash and presentation checks recorded.
- [ ] Every non-Android branch has a written retain, supersede, or merge
  disposition. No legacy gameplay branch is merged merely to clear it.
- [ ] `feat/v005-roadmap` is created from the reviewed `origin/main` commit.
- [ ] ABI 11, settings schema 6, and chronicle format 1 remain compatible, or
  an explicit release migration is approved.

## Candidate gates

- [ ] Strict C90 build, complete CTest, scalar/NASM parity, and optimization
  invariance pass from a clean build.
- [ ] `tools/vox-verify.sh`, `tools/vox-bench.sh`, the 10 MiB size gate, and
  `git diff --check` pass on the candidate.
- [ ] Linux and Windows candidate packages are built, unpacked, smoke-tested,
  checksumed, and accompanied by an SPDX SBOM.
- [ ] Manual QA covers every map style, fixture destruction, genuine terrain
  cave-ins, blood/gore impacts, fluids, dropship, replay, controller input,
  and the relationship/conversation scenarios recorded in the QA workbook.

## Publication boundary

- [ ] The version bump, changelog, package evidence, release tag, and hosted
  checks have separate review approval.
- [ ] The v0.0.3 public release remains immutable.
- [ ] Android work remains a separate future port effort.
