# v0.0.2 release checklist

## Governance and source

- [ ] RFC 0001 is accepted by a qualified reviewer and the final code matches
  its ABI, determinism, migration, and rollback contracts.
- [ ] Release candidate is a reviewed commit on protected `main`; the worktree
  is clean and every included commit has DCO sign-off.
- [ ] ABI 8 is identical in the C and Rust boundaries; Audio API 2 and settings
  schema 2 are documented with an explicit upgrade warning.
- [ ] GPL-3.0-or-later source, notices, SBOM, Corresponding Source, contributor
  credit, and reproducible build inputs accompany every binary archive.

## Automated gate

- [ ] Strict C89/C++98 headless and SDL2 builds complete without extensions or
  warnings; the scalar path is tested both with and without the NASM leaf.
- [ ] All CTests and Cargo tests pass twice with matching deterministic output.
- [ ] Input, camera, smoke, headless, script-sandbox, icon, and audio
  self-tests pass from the staged package.
- [ ] ASan/UBSan runs show no invalid access, undefined behavior, leak, queue
  overrun, or arithmetic overflow in the new match/audio/feedback paths.
- [ ] `python3 tools/build-qa-workbook.py --check` and `git diff --check` pass.

## Gameplay acceptance

- [ ] Every zoom shows only the true world-space lava horizon; close zoom has
  no false footer and overview zoom exposes no black camera region.
- [ ] Projectiles clear their shooter in open space, collide with external
  walls, and restore ordinary self-damage after the six-tick clearance window.
- [ ] Two- and three-minute matches, optional score caps, FFA/team winners,
  final-tick ties, and all four-player results are correct.
- [ ] AUTO and ON FIRE respawn work at 0/1/2/3/5 seconds; held FIRE cannot skip
  the ON FIRE release-and-press gate; bots and spawn shields remain correct.
- [ ] Human and bot names, timer, killfeed, local hit/kill confirmation,
  multikill/spree awards, hit markers, crosshair pulse, and death camera remain
  readable with one and two local players.

## Audio and accessibility acceptance

- [ ] Menu navigation produces the ordered mining motif rather than a repeated
  beep; only a successful unmodified mouse-wheel zoom produces the quiet click.
- [ ] Title/start/award announcements and all six ten-line bark contexts remain
  intelligible, deterministic, bounded, and free of copied audio or dialogue.
- [ ] Bot speech stays sparse; bot-only kills do not trigger large banners or
  announcer spam; speech bubbles match the synthesized phrase.
- [ ] Wind, water, and lava ambience follows visible world state without audio
  underruns or simulation-hash changes.
- [ ] MASTER VOLUME is the only user volume control, persists at 0--100%, and
  zero volume stays silent while audio scheduling continues.
- [ ] Flash Off/Reduced/Full, gore, shake, damage-number settings, and silent
  audio-device fallback remain functional.

## Compatibility and publication

- [ ] Frame caps 30/60/90/120/144/Unlimited preserve fixed 60 Hz results.
- [ ] Logitech F310 X/D modes, keyboard/mouse, two-controller ownership,
  hotplug, calibration, rebinding, and bark controls pass the QA workbook.
- [ ] Five paired benchmark runs on the i7-10750H laptop show no unexplained
  median regression greater than 5%; the GTX 1660 Ti is not described as an
  accelerated render path.
- [ ] Linux tester/source archives, `SHA256SUMS`, smoke hashes, benchmark logs,
  compatibility status, known limitations, and the xleak cockpit packet are
  captured from the frozen release candidate.
- [ ] `v0.0.2-rc.1` receives a clean-checkout soak before a signed `v0.0.2` tag
  is created from protected `main`.
