# v0.0.1 Linux x86-64 acceptance evidence

This record was captured on 2026-07-12 for the VOX + DIGS `v0.0.1` demo
candidate. It identifies what was actually exercised; it is not evidence for
another OS, historical adapter, GPU renderer, or machine.

## Test bench

- Ageless Linux 0.1.1 (Linux Mint 22.3 base), Linux 6.17.0-35 x86-64
- Intel Core i7-10750H, 6 cores / 12 threads
- GCC/G++ 13.3.0 and Clang/Clang++ 18.1.3
- CMake 3.28.3, Cargo 1.95.0, NASM 2.16.01, SDL2 2.30.0
- CPU RGB24 software rendering
- NVIDIA GTX 1660 Ti reported by PCI enumeration, but no usable NVIDIA driver
  or graphics device was available to this run

## Automated acceptance

`tools/vox-verify.sh` completed with extension-free strict C89 and C++98,
SDL2 enabled, and the optional NASM parity leaf enabled. All eight CTests,
the Rust workspace test, VOX and DIGS headless scenarios, and the SDL host's
non-windowed smoke test passed under GCC/G++.

The same gate passed with Clang/Clang++ after selecting the installed GCC 13
standard-library directory explicitly on this host. GCC and Clang produced
identical smoke output:

| Evidence | Value |
|---|---|
| Authoritative state hash | `86dc7ba8` |
| RGB framebuffer hash | `c3ff194e` |
| Smoke PPM SHA-256 | `438e5651d958d75b74e337ca98856907bcfcc1f7b15a361dca520fe32da87279` |
| VOX headless hash | `82072e73` |
| DIGS headless hash | `6c0bf33a` |

The optional x86-64 NASM FNV-1a leaf matched its scalar C89 oracle. A separate
NASM-disabled build exercises the fallback through the same contract.

This is one local CPU-renderer sample. It is load-, compiler-, build-, power-,
and machine-specific; it is not a frame-rate guarantee and says nothing about
GTX 1660 Ti performance. Packaged benchmark runs preserve their own raw output
so later results are not substituted for this one.

## Manual boundary

The SDL windowed executable starts and remains in its event loop, but the full
human checklist—menu navigation, input feel, every weapon, audio, resize,
fullscreen, all frame caps, pause/results, and clean shutdown—has not been
promoted to `VERIFIED` by automation. Testers record that evidence in
`qa/VOX_QA_FEEDBACK.xlsx` and combine reviewed workbooks with
`tools/vox-test-cockpit.sh`.

The compatibility matrix therefore keeps the interactive host at `BUILDS`.
That open human gate does not weaken the deterministic headless and renderer
evidence above, but it must be completed before claiming the named desktop
configuration as fully verified.
