# Third-party license directory

VOX keeps the complete license text for every vendored or distributed
dependency here. Original VOX/DIGS files use SPDX `GPL-3.0-or-later`.
Third-party files keep their original SPDX identifier and copyright notices.

No dependency may enter the runtime or source release without an origin URL,
exact version/commit, license identifier, and modification record in
`THIRD_PARTY.md`.

`SDL_GameControllerDB.txt` is the zlib license notice for the pinned controller
mapping data distributed at `share/digs/controllers/gamecontrollerdb.txt`.
